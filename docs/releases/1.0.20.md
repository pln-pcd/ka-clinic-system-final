# K&A Clinic 1.0.20 — 28 October 2026

## Patient App

- **KAI chatbot**: Clinic hours, services, contact details, booking steps and short messages are answered instantly on the phone; the chat wakes the server when it opens, so the first answer comes faster.
- **KAI services**: Lists the four services offered: PEP, PrEP, Pneumonia (pneumococcal) vaccine and Anti-tetanus vaccine.
- **KAI privacy**: A name or an introduction is never used or repeated; KAI asks the patient not to share personal details.
- **KAI prices and other questions**: Prices and questions KAI cannot answer are referred to the clinic staff.
- **Open my vaccination card**: Opens the enlarged vaccination card.
- **Overdue doses**: Shown as red "Overdue" text, without a day count or a box.
- **Home**: The arrow after "Tap to view protocol tracker" is removed.
- **Closure notice**: The Reschedule button is slightly larger.

## Admin Web

- **Incident Map**: One pin per open PEP case in the patient records, at the patient's barangay (not a house); a pin disappears once the case is completed or archived. The map is locked to Libon's municipal boundary, and a "Simulated data" label marks it.
- **Add Appointment**: Strict checks on the name (letters only) and contact number (11-digit PH mobile only), a 300-character notes limit, and a re-check that the time slot is still free on save.
- **Appointment services**: "Walk-in Emergency" is removed.
- **Schedule closures**: The Internal Note field is removed; Edit and Reopen buttons are slightly larger.
- **Patient record**: Buttons read Export Patient Record, Edit Record, then Add Another Service.
- **Roles**: The manager role is now shown as "Admin" everywhere staff see it (permissions unchanged).
