# K&A Clinic 1.0.23 — 28 October 2026

## Changes

- The Android app download is about 70% smaller: 30.4 MB, down from 103.4 MB.
- Built for real phone processors only (arm64-v8a and armeabi-v7a). The x86 and x86_64 builds, used only by PC emulators, are no longer included.
- Unused code and resources are removed from the release build, and native libraries are compressed in the APK.
- No feature changes: the app's JavaScript bundle is identical to 1.0.22.

## Verification

- APK signature valid and signed with the same certificate as 1.0.22, so it installs as an update.
- Package and version correct (`1.0.23`, version code `23`); APK archive passes an integrity check.
- HTTPS-only transport and backups disabled in the manifest; production API configured; no private server secrets in the app bundle.
- The JavaScript bundle is byte-for-byte identical to 1.0.22, so KAI's rules and every screen are unchanged.
