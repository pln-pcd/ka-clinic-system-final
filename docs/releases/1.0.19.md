# K&A Clinic 1.0.19 — 27 October 2026

## Patient App

- **Record tables**: Case & Incident Record, Dose Timeline and Previous Treatments have a light header and neutral status tags (a missed dose stays red). Same on the Records tab.
- **Appointments**: Closed days, closed slots and closure notices are gray instead of yellow. The closure card no longer says "Your appointment is still on record."
- **Reschedule**: The summary text wraps inside its card, the "waiting for the clinic's confirmation" notice is gone, and the "Current" tag is the same size as "Full" so the time fits.
- **"Appointments closed" pop-up**: One button, "Pick another date/time", which opens the next open weekend's time slots.
- **Privacy Policy & Data Notice**: Shows the data security section only.
- **High-risk condition**: When the clinic types an "Others" condition, the card shows that text.

## Admin Web

- **Barangays**: The 47 official barangays of Libon with their real map points. Poblacion is chosen once, with a required Zone I–VII; puroks are typed in.
- **Patient record page**: Restyled to match the Edit Patient form.
- **Vaccination Tracker**: A dose cannot be ticked before its scheduled date; the dose window uses less yellow.
- **Messages**: Shows the patient's app profile photo.
- **Schedule closures**: Every closure is announced to all patients automatically.
- **High-Risk Condition**: "Others" takes typed text.
- **Exported patient record**: Fewer colors. Expired stock reads "Expired".
