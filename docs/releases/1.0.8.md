# K&A Clinic 1.0.8 — 16 October 2026

## Patient app

- **My Appointments card:** the small X is replaced by an outlined "Cancel"
  pill (icon + label) placed under the status badge, with a padded tap area.
  It opens the same Request Cancellation flow as Appointment Details. When an
  appointment cannot be cancelled, an invisible pill of the same size keeps
  the badge in place, so cards never shift. Card height is unchanged.
- **Dose timeline:** columns rebalanced (Dose 1.75 / Vaccine 1.45 / Date 1.1 /
  Status 0.95) so "Session 4 (Day 28)" stays on one line from 320 px up. The
  previous-treatment viewer uses the same table.
- **"Open my vaccination card" (KAI):** Home used a fixed `scrollTo(340)`, which
  ignored the real position of the card (banner height, status bar, scrolled
  state). Home now measures the card's position and scrolls its top just below
  the status bar; a request made before Home has laid out waits for layout
  (up to 1.5 s).
- **KAI medical detection:** a medical vocabulary (diseases, symptoms,
  medicines and brand names, vaccines, treatments, Filipino terms) with
  spelling tolerance ("pnuemonia", "paracetmol") in any letter case, plus body
  parts when paired with a health word ("my arm hurts"). These get the medical
  refusal; "tell me more" is only for vague non-medical messages. Account
  questions ("forgot my password") and service questions ("do you offer
  pneumonia vaccine?") still get their normal answers.
- **Faster opening:** returning users (guest or kept signed in) see Home from
  the saved session at once; the network session refresh and device trust
  check run in the background. If the server says the device is no longer
  trusted, the user is signed out as before. Onboarding images downscaled
  2000 → 1000 px.
- **Sign-up:** after creating the account the app opens Sign in with the MRN
  filled in. The password is still required, but the second sign-in code is
  skipped once (a one-time pass, valid 15 minutes, bound to this device).
- **Onboarding:** native slide transition (320 ms, eased; 150 ms fade when
  Reduce Motion is on). Illustration and text enter with a short staggered
  fade on the UI thread (Reanimated), and the progress dot grows into place.
  Back, Next and swipe-back move the same way.

## API

- `completeSignup` returns a one-time `signupPass` for the device; the
  sign-in trust check accepts it once and then either replaces it with a
  30-day device token ("Keep me signed in") or removes it. `customToken` is
  still returned for older app versions.

## Verification

- KAI scope: 94/94 prompts on the server and app rules.
- Card/timeline test at 320/360/393/412 px: session labels on one line.
- Typecheck, admin build: pass.
- Android emulator, returning guest, cold start to Home (`am start -W`,
  10 runs each): 1.0.7 median 2.89 s, 1.0.8 median 1.45 s. Home renders
  ~0.21 s after JS starts (1.0.7 waited ~1.1 s for the session restore).
- Emulator: "Open my vaccination card" from a scrolled Home lands on the top
  of the card.
- Not run: real-account sign-in and sign-up, physical phones.
