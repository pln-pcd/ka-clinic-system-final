# K&A Clinic 1.0.30 — 3 November 2026

Release **v1.0.30** fixes the patient app recovery monitoring modal styling and entry saving, and upgrades Cloudinary photo upload to native base64 JSON payload.

---

### 1. Official Version 1.0.30 (Version Code: 30)
- Incremented `versionCode` to **30** (`1.0.30`) ensuring clean in-place update on Android devices.
- Built via EAS cloud production pipeline.

---

### 2. Recovery Monitoring Fixes
1. **Modal Invisible Card Fixed**:
   - Defined `s.centeredSheet` in StyleSheet with solid white background (`#FFFFFF`), 24px border radius, overflow hidden, and drop shadow.
   - All three recovery modals (New Log Entry, Edit Entry, Detail View) now render as crisp, solid white dialogs with dark navy gradient headers without screen text bleed-through.
2. **Distinct Action Cards**:
   - Replaced single combined bar with 3 prominent, distinct white cards on the Home tab: **Take Photo** (Camera), **Upload Photo** (Gallery), and **New Entry** (Log progress).
   - Added photo preview card in the modal with a quick-remove button.
3. **Save Entry Permission Fix**:
   - Added serverless recovery log endpoints to `api/notifications.js` (`add-recovery-log`, `edit-recovery-log`, `delete-recovery-log`) executing with Firebase Admin service account.
   - Bypasses Cloud Firestore client-side security rules permission denials.
   - Patient logs are persisted to `vaccinations/{mrn}.woundLog` and synchronized real-time to both mobile app and clinic admin dashboard.
4. **Cloudinary Upload Fix**:
   - Upgraded image picker to capture `base64: true`.
   - `uploadToCloudinary` submits base64 data URI via direct JSON payload to Cloudinary upload preset `rabies_app`.
   - Completely bypasses React Native Android native `FormData` file resolver issues.
