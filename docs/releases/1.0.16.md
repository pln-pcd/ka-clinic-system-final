# K&A Clinic 1.0.16 — 27 October 2026

## Patient App

- **Vaccination card**: The card on Home now fits its content, removing the empty band under the dose table. Both sides are measured, so neither the front nor the back is ever cut off.
- **Sign-up code screen**: The line telling the patient where the code was sent now reads cleanly ("sent to the email on file for this MRN") instead of breaking mid-sentence. For privacy, the sign-up screen does not reveal any part of the email address before the patient has proven they own the record.
