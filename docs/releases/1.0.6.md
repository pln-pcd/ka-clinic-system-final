# K&A Clinic 1.0.6 — 16 October 2026

## Patient app

- **Vaccination card** is back to its original size (padding, logos, fonts,
  field rows, table cells from before 1.0.5). Front and back share one height,
  set by the front; the back shows three fields to a row (age and sex
  combined, no section headings) so it fits. Exports stay the same size.
  The Libon seal and the dose Status column are kept.
- **Dose timeline** is the original table design again; cells wrap instead of
  cutting text off.
- **Previous Treatments** table under the timeline (only when earlier
  treatments exist): service, started, doses, completed, status, category for
  PEP only. Tapping a row opens that treatment's card (same card, tagged
  "PREVIOUS TREATMENT · start – end") with flip and export.
- **My Appointments:** status label above the cancel button, right-aligned.
- **KAI:** personal-detail questions get a "which screen" reply, bare topic
  words ("rabies") get a "what do you need?" reply, medical questions get the
  refusal with the disclaimer. One disclaimer sentence everywhere, pinned
  under the header. The "Talk to clinic staff?" pop-up opens only from the
  new "Talk to clinic staff" button.
- **Staff chat:** no more false "You do not have permission to send
  messages" banner; a message that fails shows "Not sent · Tap to retry".
  Guests are asked to sign in.

## Server and rules

- `firestore.rules`: a patient sending a message may set `status: 'pending'`
  and `unread: true` on their own thread (the refused update was the cause of
  the false permission error, and kept new messages from showing as unread
  in the admin inbox).
- `api/chatbot.js`: same reply types as the app.

## Verification

- Firestore rules on the emulator: 742/742 passed (including the chat cases;
  the previous rules fail "patient updates own thread after sending").
- KAI scope: 68/68 prompts on server and app rules; chat UI test (guest,
  local emulators): correct reply type for all ten test prompts, no automatic
  pop-up, disclaimer pinned.
- Card/table test at 320–412 px: equal faces and exports, back fits the
  front, nothing clipped, fields match the dashboard rules, 0/1/2 previous
  treatments.
- Not run: signed-in staff chat end to end, physical phones.
