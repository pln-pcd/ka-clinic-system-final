# K&A Clinic 1.0.12 — 20 October 2026

## Fixes & Improvements

- **Vaccination Card Inner Padding & Layout Fit**:
  - Added ~6% horizontal inner padding (`padX: scale(35)` for pop-up, `scale(22)` for inline) and balanced vertical margins across front and back card faces.
  - Placed inner padding directly inside `st.cardBody` within the `ViewShot` container so exported gallery PNGs and on-screen views share the identical balanced breathing room without clipping logos, text, or dose tables.
  - Locked outer card height across all services (PEP, PrEP, Anti-Tetanus, Pneumonia, Booster) and historical previous-treatment cards to the fixed 4-dose reference standard (`minHeight = 415px` popup / `346px` inline).
  - Re-balanced table flex ratios (`COLS = [1.65, 1.65, 1.05, 0.8]`) ensuring long vaccine names (e.g. *Verorab (PVRV Rabies Vaccine)*) and long patient names fit cleanly without text truncation.

- **Grouped List View for Appointments & Cancelled Visits**:
  - Converted standalone appointment cards in "My Appointments", "Past Appointments", and "Cancelled" into structured, cohesive list containers (`apptListCard`).
  - Rows are separated by clean dividers (`apptListDivider`) indented past the date badge, aligning with standard iOS/Android list design.

- **Account Profile "Service" Stat**:
  - Replaced "Category" with "Service" in the profile header stats row.
  - Dynamically displays the patient's active service abbreviation (`PEP`, `PrEP`, `Anti-Tetanus`, `Pneumonia`, `Booster`) from shared clinic configuration.
  - Patients with only completed regimens show their most recent service; patients without active cases or browsing in Guest Mode display an em dash (`—`).
  - Aligned "Doses" and "Next Dose" to calculate dose completion using `doseState(d, clinicToday())`, ensuring 100% parity with the Home screen dose timeline and vaccination card.

- **Web Portal Logo Enhancements (Login & Accept Invite)**:
  - Enlarged the K&A clinic logo inside the white tile by ~21% on the Admin Login page (`LoginPage.jsx`) and Accept Invite page (`AcceptInvitePage.jsx`).
  - Outer tile size (40×40px and 44×44px), positioning, and surrounding layout remain unchanged.

- **Auth Screen Copy & Clean Notification Policy**:
  - Streamlined signup navigation link from *"or you can Sign in if you have an existing account Sign In"* to clean *"Already have an account? Sign In"*.
  - Enforced zero-emoji policy across all system push notifications and local alert banners (removed `🔔` and `💉`).
