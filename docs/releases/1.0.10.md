# K&A Clinic 1.0.10 — 17 October 2026

## Fix

- **"Something went wrong — This screen couldn't load" on every signed-in
  or guest screen (1.0.9).** 1.0.9 added a screenshot preview check in
  `components/AppShells.tsx` that read `window.location.search`. On a phone
  `window` exists but `window.location` does not, so the check threw
  `TypeError: Cannot read property 'search' of undefined` as soon as Home
  opened. The check now runs on the web build only.
- **Preview sample data is web-only.** The `?preview=1` mode added in 1.0.9
  (sample appointments, devices, personal details, records, and the skipped
  guest booking check) is now limited to the web build
  (`utils/preview.ts`), so it can never show on a phone.
- Type errors from 1.0.9 fixed (preview device rows, OTP screen params).

## Signing

- The 1.0.9 APK was signed with a different certificate
  (`4d4e16a8…`) than the clinic release key used for 1.0.5–1.0.8. 1.0.10 is
  signed with the release key again (`4fef45c1…`), so it updates 1.0.8 in
  place. Phones that installed the 1.0.9 APK must uninstall it once before
  installing 1.0.10.

## Verification

- Android emulator: 1.0.9 reproduces the crash after "Continue as a Guest";
  1.0.10 opens Home, Appointments, Chat and Account with no JS errors, and a
  cold restart reopens Home in about 1.5 s.
- Typecheck passes.
