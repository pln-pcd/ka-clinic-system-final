# K&A Clinic 1.0.24 — 28 October 2026

## Changes

- KAI answers app and clinic questions more naturally. Cleared questions (navigation, account, sign-in, Forgot Password, booking, cancel, reschedule, hours, location, contact, the app and its creators) get a flexible answer grounded in the app guide and approved clinic facts, then checked again before it is shown. If that check fails or the server is unreachable, KAI uses its fixed approved reply.
- KAI replies in the language the patient uses: English, Filipino or Taglish.
- KAI reads "bukas" from the sentence: "May slot pa ba bukas?" means tomorrow (shows tomorrow's availability); "Bukas po ba kayo?" and "Anong oras kayo magbubukas?" mean open (shows clinic hours).
- Corrected answers: cancelling an appointment frees the slot right away; rescheduling is done by tapping the appointment and choosing Reschedule; Forgot Password uses the MRN.
- KAI uses the app's real tab names (Home, Appointments, Chat, Account) and the Enlarge Card button.
- Restrictions unchanged: no medical advice, no personal details or staff names, off-topic questions refused, rates and services answered only from approved clinic data.

## Verification

- 98 KAI policy, server and model tests pass, including: the model is never called for medical, private, off-topic, rate or service questions; unsafe model output (clinical advice, emails, phone numbers) is discarded.
