# K&A Clinic 1.0.7 — 16 October 2026

## Patient app

- **Stuck logo fixed.** Returning users could stay on the logo forever: the
  splash was hidden by a timer in the start screen, and the start screen's
  own redirect unmounted it and cancelled that timer (1.0.5 and 1.0.6). The
  always-mounted app shell now hides it. Every startup network step has a
  deadline (trust check 8 s, session refresh 10 s, local reads 3 s), startup
  errors open the sign-in screen instead of hanging, and two safety nets
  (15 s, 20 s) hide the splash whatever happens. With no internet, a device
  that already passed the sign-in code opens Home from its cached record and
  re-checks with the server when it is back online.
- **KAI:** single medical words ("vaccine", "rabies", "dose", "booster",
  "medicine", "PEP", "wound") get the medical refusal; "tell me more" is only
  for non-medical vague messages ("hello", "help", "?"). Fixed replies use one
  bold rule (only a reply's title line is bold). List items and numbered steps
  wrap with a hanging indent. "How do I book an appointment?" lists the six
  real steps in the app.
- **"Talk to clinic staff" button:** after a medical reply it no longer shows
  as an empty navy bar on Android.
- **Sign-in code:** verifies automatically on the 6th digit, on paste and on
  keyboard autofill; no double submission; a wrong code clears the boxes and
  refocuses the first one; the button stays as a fallback.
- **Booking:** the time-slot hold and the appointment are saved in one
  transaction, so a failed booking can no longer leave a slot "Full" with no
  appointment behind it.
- **Dose timeline:** the Dosage column is removed.
- **Vaccination card:** the Status column is narrower, so "Session N (Day N)"
  fits on one line. The back no longer repeats the dose schedule; it shows a
  Clinical Notes box (the new patient-facing note) that fills the space below
  the profile fields, or "No clinical notes".

## Admin dashboard

- New **"Note for patient (shown on their vaccination card)"** field in the
  Register and Edit forms, kept per treatment (saved in the treatment's
  history when a new service is added). The existing clinical notes are now
  labelled "Clinical notes (staff only)" and are never shown to patients.
- Appointment availability uses the same slot holds as the patient app.

## Verification

- KAI scope: 80/80 prompts on the server and app rules.
- Chat UI test (local emulators): all test prompts get the right reply type,
  no automatic pop-up, disclaimer pinned.
- Card test at 320–412 px: equal faces and exports, front sets the height,
  nothing clipped, dose labels on one line at 360 px and up.
- Android emulator with this APK: returning launch opens Home (1.0.6 stayed
  on the logo), offline launch opens, and the staff button shows its label
  after a medical reply.
- Live slot audit (`scripts/audit-slots.mjs`): 10 holds, 0 orphans. The
  Oct 25, 1:00 PM slot is held by a confirmed appointment (sample data).
- Not run: signed-in sign-in/OTP on a real account, physical phones.
